# بوابة صيانة المعدات

موقع عربي لملفات الماكينات والأوناش، حالة كل معدة، سجل الصيانة، ورمز QR يفتح الملف مباشرة على الهاتف.

## البيانات

استُخرجت **18 ماكينة و16 ونشًا** من `New Microsoft Excel Worksheet-2.xlsx`. الخانات الفارغة بقيت فارغة، والحالة الابتدائية لكل معدة هي `غير محددة` لأن الملف لا يذكر حالة التشغيل. ملف البيانات الأولية هو `src/equipment.json`.

## التشغيل المحلي

```powershell
npm.cmd install
npm.cmd run dev
```

دون إعداد Supabase يعمل الموقع في وضع تجريبي داخل المتصفح. التغييرات فيه تُحفظ في `localStorage` لهذا المتصفح فقط. رمز QR في هذا الوضع يشير إلى رابط الموقع الحالي، ولذلك يجب ربط Supabase ونشر الموقع قبل طباعة الملصقات النهائية.

## ربط Supabase

1. أنشئ مشروع Supabase.
2. نفّذ `supabase/schema.sql` في SQL Editor ثم `supabase/seed.sql` لإضافة المعدات.
3. أنشئ مستخدمًا لمسؤول الصيانة من **Authentication > Users**، ثم أضف UUID الخاص به في `public.maintenance_admins` باستخدام أمر الإدراج الموجود أسفل `schema.sql`.
4. انسخ `.env.example` إلى `.env.local`، وضع رابط المشروع ومفتاح **publishable** فقط. لا تضع secret أو service role key في ملفات الواجهة.
5. شغّل `npm.cmd run build` وأعد نشر الموقع. بعد الربط تصبح ملفات المعدات عامة للقراءة عبر QR، بينما تعديلها وملاحظات الصيانة يتطلبان دخول مسؤول الصيانة.

ملفات الصور وPDF لتفاصيل الصيانة مؤجلة، كما ورد في نطاق الطلب الحالي. سجل الصيانة يدعم التاريخ والملاحظات ونوع العملية والحالة بعدها.
