# بوابة صيانة المعدات

واجهة عربية لملفات المعدات، الحالة الحالية، سجل الصيانة، ورموز QR. البيانات الأصلية تشمل 18 ماكينة و16 ونشًا من ملف الإكسيل؛ الخانات الناقصة بقيت فارغة، وحالة كل معدة بدأت «غير محددة».

## البنية

| المجلد                     | المسؤولية                                                    |
| -------------------------- | ------------------------------------------------------------ |
| `src/domain`               | أنواع البيانات والقيم المسموحة للمعدات والصيانة.             |
| `src/services`             | عقد مستودع البيانات وتنفيذاه: Supabase ونسخة محلية للتجربة.  |
| `src/features/auth`        | الجلسة والتحقق من عضوية `maintenance_admins` ونموذج الدخول.  |
| `src/features/equipment`   | لوحة المعدات، الملف، النماذج، واستعلامات المعدات.            |
| `src/features/maintenance` | سجل الصيانة وإضافة عملية جديدة.                              |
| `src/shared`               | واجهات متكررة مثل Modal وStatusBadge وQrCard وتنسيق التاريخ. |
| `src/app`                  | مزودو التطبيق والمسارات والقالب العام.                       |

تستخدم الواجهة React وTypeScript وReact Router وTanStack Query. كل تغيير في البيانات يمر عبر `MaintenanceRepository` ثم يحدّث الاستعلامات المعنية. رابط QR يستخدم مسارًا ثابتًا في عنوان الموقع. صلاحيات الكتابة تتحقق في قاعدة البيانات عبر RLS، وليس من إخفاء الأزرار فقط.

## تشغيل وفحص

```powershell
npm.cmd ci
npm.cmd run dev
npm.cmd run format:check
npm.cmd run build
node scripts/check-supabase.mjs
```

الإنتاج متصل بمشروع Supabase المحدد في `.env.production` باستخدام **المفتاح العام Publishable**. المفتاح السري لا يدخل في الواجهة. يمكن استخدام `.env.local` لتغيير إعدادات الجهاز دون إضافتها إلى Git. عند غياب الإعدادات يعمل مستودع محلي تجريبي داخل المتصفح.

`supabase/schema.sql` يجهز الجداول والصلاحيات، و`supabase/seed.sql` يضيف المعدات الأصلية. ملاحظات الصيانة متاحة فقط لمسؤول مسجل في `maintenance_admins`؛ ملف المعدة العام يعرض تفاصيلها وحالتها وتاريخ آخر صيانة. لإضافة مسؤول، أنشئ مستخدمًا في **Authentication > Users** ثم أضف UUID الخاص به بالأمر أسفل `schema.sql`.

صور وPDF الصيانة مؤجلة حسب النطاق الحالي. عند إضافتها لاحقًا تُنشأ طبقة تخزين مستقلة مع سياسات وصول مناسبة.
